# GAGA 0.0.38.2

## Shell Context Contract

Second direct Rempah Ruah capability extraction sprint.

### Added
- domain-neutral shell context contract
- explicit left/right/mobile context roles
- right-context priority contract
- context identity projected on both document and app-frame boundaries
- polite global context status region for progressive runtime feedback
- inspector marker on the existing right information rail
- compact `navigation-only` policy for system surfaces

### Context modes
- discovery
- reading
- reference
- system

### Architecture
Workspace identity answers **where the user is**.
Shell context answers **what the surrounding interface should prioritize**.

The runtime continues to own open/collapsed presentation state. The new contract does not duplicate event handling.

### Non-goals
- no redesign
- no new hydration framework
- no Rempah Ruah product/buyer domain logic
- no routing or MDX changes
