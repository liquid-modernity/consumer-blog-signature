# GAGA 0.0.38.5

## Reading Continuity + Freshness Authority

### Added
- reading-continuity policy-as-code
- freshness policy-as-code
- public/indexable eligibility gate for reading history
- user reset control for reading history
- native freshness resolver and shell data contracts
- freshness metadata in the GAGA head
- freshness projection into machine/search discovery records
- continuity/freshness source audit integrated into signature validation

### Preserved
- existing GAGA reading-continuity engine and storage format
- current Saved/Library surface
- static-first publishing model
- no server-side reading-history sync

### Semantics
Freshness signals describe editorial review governance. They are not claims of factual correctness.
