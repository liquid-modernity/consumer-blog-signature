# GAGA 0.0.40.1

## Section Fronts + Editorial Hierarchy

### Added
- first-class Sections workspace
- `/sections` index
- static `/sections/{slug}` routes
- section index and section front components
- section-aware navigation and shell context
- section sitemap projection
- section search/machine discovery records
- section-front policy-as-code and audit

### Architecture
Sections are derived from article editorial metadata. No duplicate content authority or section database is introduced.

### Portal capability
A Consumer Blog Signature publication can now organize the same article collection into multiple newsroom-style section fronts while retaining ordinary blog compatibility.
