# GAGA 0.0.42.0 Visual + Reading Surface Polish

This iteration starts the final presentation phase.

## Article surface
- stronger article header hierarchy
- tighter breadcrumb treatment
- controlled title/dek measure
- more deliberate paragraph and heading rhythm
- polished native blockquote, code, table, figure and caption surfaces
- less visually dominant reading chrome

## Discovery/editorial surfaces
- more coherent lead/card/list hierarchy
- denser section and editorial fronts
- normalized topic/tag/search/entity presentation
- discovery cards are isolated from reader width preferences

## Responsive behavior
- article spacing scales down without collapsing hierarchy
- mobile code blocks may use the full viewport edge
- focus visibility and reduced-motion behavior remain intact

No new routes, schemas or publishing capabilities are introduced.
