# Search and Machine Discovery Foundation

GAGA 0.0.38.4 establishes one public discovery projection that can feed human search and machine-readable surfaces without creating a second content authority.

## Surfaces
- `/search-index.json`: current article-search compatibility plus rich records
- `/machine.json`: project-defined public publication index
- `/agent.json`: project-defined descriptive capability document
- `/llms.txt`: informational discovery guidance
- `/rss.xml`: publication feed
- `/sitemap-index.xml`: crawl discovery

Canonical public pages remain authoritative. Machine-readable indexes are discovery projections and must not invent additional editorial claims.
