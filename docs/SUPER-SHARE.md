# Super Share V1

Application-owned content distribution through the existing Contextual Surface family. The command ID remains `share-page`; its public label is **Super Share**. It opens the existing Notch `panel` geometry, with no fifth surface role, new preference or storage model.

Notch uses the active eligible public content/document identity. Selection Menu offers Super Share under its existing compact secondary actions; it snapshots the exact current valid selection without requiring a saved Quote. Direct selection Copy remains unchanged. The redundant Notch Copy Link projection is removed; Link is one action after opening Super Share.

## Truthful actions

| Action | Output and boundary |
| --- | --- |
| Copy Link | Public configured canonical URL only |
| Rich Link | Authoritative title and canonical URL, portable plain text |
| Quote | Exact selected fragment, title, optional authoritative author, public URL; an explicit existing block ID only when available |
| Reference | Canonical web reference with optional authoritative author/date; no formal citation-style claim |
| Text Card | Deterministic UTF-8 `.txt` download; full fragment/source identity |
| Poster PNG | Browser-local1080×1350 editorial canvas; off-white paper, black type, configured site identity, source URL. No external rendering/font/upload service. Large selections omit this action; encoding/layout failure retains Text Card as an honest alternative |
| Native Share | Existing public Engine0.4.0 `runtime/share` capability with actual browser availability/payload check. Cancellation is distinct from failure. Browser qualification uses stubs; real OS destinations are not certified |

PDF is omitted. Existing print CSS only addresses part of document navigation, not a validated publication/document pagination/export contract. No dead PDF command or claim of generated PDF. Native file sharing, social integrations, shortening and QR are outside V1.

## Authority, privacy and appearance

`src/features/super-share/model.mjs` resolves a small immutable public payload from current canonical identity, not hovered links or preview origins. It never reads notes/history/highlights for distribution. Selection capture remains the qualified Engine annotation path; uncertain personal anchors are never promoted into precise references. Only explicit copy/download/native actions distribute payloads. No automatic network mutation, telemetry or CMS writes. Public Search/machine/feed data and Personal State persistence remain unchanged.

The panel lives in the existing command material and inherits density, radius, contrast, focus, icon and reduced-motion semantics. Notch expanded state supplies existing pinning and bounded geometry. Escape returns to the initiating command or source block. Pointer/touch and outside dismissal retain native Notch ownership. Super Share does not appear in Outline or Preview.

## Qualification and preservation

Small shared synthetic fixtures cover whole/selection/incomplete metadata, unsupported capabilities and narrow geometry. Browser suites prove actual clipboard values, exact quotes, PNG dimensions/encoding/repeated-byte identity, native outcomes, no network writes, keyboard/focus, appearance and containment. Existing74 browsers remain required; the former overflow Copy Link visibility check now asserts canonical Super Share visibility and no competing Copy Link projection, with actual copying protected by Super Share tests.

The historical annotation-controller byte proof excludes only the exact additive Super Share import, validated selection-entry hook and disclosure collision refresh; a fail-closed guard test rejects altered/missing/duplicate hooks. All prior annotation capture/persistence/anchoring and motion/preview controllers remain protected. Exact UI profile admission remains mandatory before release; no historical inventory refresh.

First-consumer extraction pressure is recorded for Arsenal Experience/Application composition. Site only supplies existing metadata; Engine public share/storage ports suffice; Corps has no demonstrated gap. Record only, no package/API extraction or second-consumer claim.

The existing `src/features/super-share` namespace is reused. Its earlier composer `open/close` and runtime adapter are unconsumed scaffold contracts, not functional export/render mechanisms. Existing `src/gaga/share` channels have no active caller; the active inline site Share handler is replaced, not duplicated. Old console-only share audit scripts are not treated as qualification evidence.

Selected text means the browser Selection string (also captured by the public Engine annotation contract), not raw DOM whitespace. Super Share validates the unchanged source block, content identity and both original range boundaries before opening; it never relaxes the qualified annotation persistence validator. Secondary selection disclosure reuses the existing collision placement after resizing.
