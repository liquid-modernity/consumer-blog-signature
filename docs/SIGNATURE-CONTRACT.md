# Signature Contract 0.0.1

## Layout
Desktop = global navigation icon-only (far-left) + context left rail + main canvas + context right rail. Tablet large = global icon rail + collapsed left rail + optional right rail. Tablet mini/mobile use dock + outline/context peek and support full-bleed media.

## Product policy
Identity, routes, capabilities, actions, experience, and design are configurable. Site-purpose assumptions do not belong in the kernel or reusable components.

## Interaction baseline
Smart back, smart share, save/library, focus mode, adaptive labels, keyboard, mouse, touch, motion, SFX preference, reading continuity, outline peek. Annotation/highlight and spoken-content are wired to Gaga Engine runtime as first-pass reader actions; deeper library projection and block-level speech remain extensible.

## Design
Design language and appearance are independent. Blueprintism is the default reference language; editorial/minimal are first-class expansion targets, with brutalism/corporate/futuristic reserved as compatible packs.
