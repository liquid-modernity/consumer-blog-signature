# consumer-blog-signature architecture

`consumer-blog-signature` is a consumer application. Gaga Engine is an external npm kernel. Astro renders the site.

Desktop and tablet-large use four horizontal zones: vertical icon-only global navigation at the far left, context-aware left rail, main canvas, and context-aware right rail. Compact layouts replace persistent rails with mobile dock, outline/context peek, and full-bleed media capability.

Product policy is centralized in `src/config/`: capabilities, actions, routes, experience, design, identity, navigation, reader preferences, and deployment environment.
