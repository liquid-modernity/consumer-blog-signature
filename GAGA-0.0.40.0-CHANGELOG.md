# GAGA 0.0.40.0

## Editorial Front Projection

### Added
- optional newsroom article metadata contract
- deterministic editorial projection engine
- native editorial front component
- responsive lead/highlight/latest/section surface
- editorial metadata in machine discovery
- editorial projection policy-as-code and audit

### Preserved
- ordinary article authoring remains valid without newsroom metadata
- canonical content collection remains the only content authority
- archive/topic/author surfaces remain unchanged
- static-first architecture

### Direction
This is the first publishing-surface expansion toward magazine/newsroom/portal use cases. It is not a BBC/NYTimes clone and does not add CMS workflow or permissions yet.
