# GAGA 0.0.41.0

## Context-Aware Rail & Workspace Maturity

### Consolidated signature ownership
- Dynamic Global Navigation becomes the canonical global destination authority
- Dynamic Notch Island becomes the canonical context-surface trigger
- Dynamic Outline Peek becomes the canonical article outline surface
- left rail becomes route-local context only on desktop
- right rail becomes context intelligence only
- Gaga Dock remains compact quick actions

### Removed duplication
- duplicate left-rail global brand
- duplicate left-rail global search
- standalone floating ContextSurfaceTrigger
- duplicate `info-rail` action inside the Notch Island
- right-rail outline priority

### Context maturity
- first-class Tags and Search workspaces
- native and standalone routes share context projection
- route-aware context groups for articles, sections, topics, tags, authors, archive, library, system and generic pages
- wider discovery workspace measure for editorial fronts

### Engine readiness
- signature-surface ownership contract
- explicit site-vs-engine extraction boundary
- extraction deferred until 0.0.41.x UI APIs are stable
